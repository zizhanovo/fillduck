# 商店文案（中文）

上架 Chrome 应用商店与 Edge 加载项商店时，逐项复制下面的内容。

## 名称（≤45 字符）

```
填鸭 FillDuck — 表单一口填
```

## 简介 / Summary（≤132 字符）

```
资料存一次，表单填一口。按资料卡自动填写网页表单，逐项告诉你填了什么。资料只存本机，最终提交永远由你自己点。
```

## 类别

生产工具（Productivity）

## 语言

中文（简体）

## 详细说明

```
填鸭是一个帮你少打字的浏览器侧边栏插件。

把姓名、电话、地址、公司信息存成一张「资料卡」，之后遇到网页表单，打开侧边栏点一下「一口填完」，它就把该填的框一个个填好，并逐项告诉你：哪些填上了、填了什么、哪些跳过了、为什么。

■ 它怎么填
· 通用填写：任何网站都能用。先看输入框自带的自动填写属性，再看输入框旁边的文字，最后按中英文关键词匹配。
· 站点配方：针对老式政务网站，把「先填哪个、后填哪个、点哪个候选项」写成一份配方，一次填对。内置「全国12315举报」配方，覆盖须知、选企业、举报人、业务信息四页。
· 配方是纯数据，不含任何代码，所以别人分享给你的配方不会在你的浏览器里跑程序。

■ 它不做什么
· 不替你点最终的「提交」按钮，只把它高亮出来，由你自己核对后点。
· 不往密码框里填任何东西，也不提供密码、银行卡类字段。
· 已经填了内容的框保持原样，不会被覆盖。
· 没有后端服务器，不发任何网络请求，没有统计和广告，不含远程代码。

■ 你的资料在哪
只在你自己电脑的浏览器里，明文保存。可以随时导出成文件带走，也可以一键删除。卸载插件时会一并清除。附件只存在侧边栏内存里，关掉就没了。

■ 权限说明
只有你点「一口填完」的那一刻，插件才会向当前标签页注入填写脚本；不点就不注入，也不会在后台读取网页内容。12315 是内置站点，其他网站在你第一次使用时由你授权。

■ 谁适合用
· 经常填政务、办事、报名类表单的人
· 需要反复填同一套公司或案件信息的人
· 想把填表交给自己的 AI 助手的人（另有配套的 agent skill）

开源，MIT 许可：https://github.com/zizhanovo/fillduck
```

## 单一用途说明（Single purpose）

```
本插件只做一件事：在用户点击时，把用户自己保存在本机的资料，填进用户当前打开的网页表单，并逐字段报告填写结果。
```

## 权限理由（逐项）

| 权限 | 理由（复制到表单） |
| --- | --- |
| `activeTab` | 用户点击「一口填完」时，需要知道当前标签页并向其注入填写脚本。 |
| `scripting` | 填写逻辑以脚本形式注入当前标签页执行；这是插件的核心功能。 |
| `storage` | 在本机保存用户自己创建的资料卡与当前选中项。数据不离开本机。 |
| `unlimitedStorage` | 资料卡可能包含较长的文本字段（例如上千字的案件描述），避免触及默认存储上限。 |
| `sidePanel` | 插件界面以侧边栏形式呈现，便于用户在填写表单的同时查看资料卡与填写结果。 |
| 主机权限 `https://www.12315.cn/*` | 内置的「全国12315举报」站点配方需要在该站点执行填写。 |
| 可选主机权限 `<all_urls>` | 通用填写功能需要能在用户指定的任意网站上运行。该权限为可选权限，仅在用户第一次在某个网站点击填写时请求，用户可以拒绝。插件不会在后台使用该权限读取网页。 |

## 数据用途声明（Data usage）

- 收集的数据类型：**个人身份信息**（姓名、电话、邮箱、地址等，由用户自行填写并保存在本机）。
- 是否传输到第三方：**否**。插件不发起任何网络请求。
- 是否出售数据：**否**。
- 是否用于与核心功能无关的用途：**否**。
- 是否用于信用评估或放贷：**否**。
- 隐私政策网址：`https://github.com/zizhanovo/fillduck/blob/main/docs/PRIVACY.md`
