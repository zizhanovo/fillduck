# 12315 举报（配方 12315-jubao）

## 案件卡字段

| 字段 | 位置 | 约束 / 说明 |
|---|---|---|
| 公司名称 | `fields.company` | 举报对象页搜索用；网购时作为入驻商户名称（≤50 字）。为空则电商平台弹窗按「举报平台本身」 |
| 统一社会信用代码 | `fields.creditCode` | 有则优先按代码搜索，更准 |
| 详细地址 | `fields.address` | 举报人地址，≤40 字 |
| 商品名称 | custom | 必填 |
| 商品类别 | custom | 必填，文字须与页面候选项完全一致 |
| 其他类别描述 | custom | 可选；只能汉字，不含「其他」「其它」 |
| 销售方式 | custom | 必填，与页面选项文字一致（如「网购」） |
| 电商平台 | custom | 网购时必填；按平台清单名称全等匹配（微信填「腾讯」）；清单外手填 ≤20 字 |
| 订单号 | custom | 可选 |
| 举报问题类别 | custom | 必填，文字须与页面候选项完全一致 |
| 其他问题类别 | custom | 可选；只能汉字，不含「其他」「其它」 |
| 医药腐败 | custom | 「是」或「否」 |
| 处理单位 | custom | 必填，三段 `省/市/区局`，每段与级联选项文字一致 |
| 举报内容 | custom | 必填，去首尾空白后 1–400 字，只写有证据的事实 |

附件：最多 4 个，单个 ≤5MB，jpg/jpeg/png/pdf/mp3/mp4。

## 四步执行

用户须已登录，从须知页进入。每一步：注入 → `run` → 看结果 → 页面跳转后重注入。

| 步骤 | 路径 | 配方做什么 | 常见失败 |
|---|---|---|---|
| 举报须知 | `/cuser/portal/jbcase/notice` | 等 `#agree` 倒计时结束（最多 15 秒）后点同意 | 超时：再跑一次 |
| 举报对象 | `/cuser/portal/jbcase/corperation` | 按信用代码或企业名称搜索，恰好一条完全匹配才选择并确认 | 0 条或多条：`candidates` 交给用户选 |
| 举报人信息 | `/cuser/portal/jbcase/customer` | 填地址（≤40 字）后点下一步 | 地址超长：先压缩 |
| 业务信息（最终步） | `/cuser/portal/jbcase/information` | 按固定顺序填全部字段，高亮提交按钮，不点击 | 见 SKILL.md 第 6 节 |

业务信息页固定顺序：商品名称 → 商品类别 → 其他类别描述 → 销售方式 → 电商平台 → 订单号 → 举报问题类别 → 其他问题类别 → 医药腐败 → 处理单位 → 举报内容 → 附件。不要调换，也不要在填完后单独改前面的类别或销售方式。
